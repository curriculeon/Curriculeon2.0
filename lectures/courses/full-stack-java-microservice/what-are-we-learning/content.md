# What Are We Learning?

This course teaches "Full Stack Java Development".
When we say Stack we mean "The technologies used to produce the final software".
Some parts of the Stack you just can't avoid... (Like Command line, Git, HTML, CSS, and JavaScript)
Other parts of the Stack you can select based on your preference (java, python, maven, nodejs etc.)

The Stack should consist of the following layers

- version-control
- git or svn

- browser front-end
- html is our only viable option here

- browser styling
- css, or scss, or sass works here
- they're basically all the same though, so just need to know one.

- browser controls
- JavaScript is our only viable option here
- Rust is emerging as a new browser-control language, but it's not as widely supported

- server controls
- Java, Python, NodeJS are just a few, but this is where the list gets LONG.
- You typically *prefer* the server to be written in only **one** of these languages.

- database
- MySQL is the standard; there are different *dialects*
- PostgreSQL is my preferred dialect because it is 100% free and open source

- Cloud Deployment
- Render.com is my preference because it is free.
- AWS, GCP, Azure, Linnode are the widely used alternatives (but they cost cash)

This course teaches how to build a *Full Stack* application using the following stack:

- git and Github
- html
- css
- JavaScript
- Java
- MySQL
- Render.com
After *completing* your understanding of **any stack**, the skills are more than 85% transferrable to every other language.
That is: Knowing how to build with 1 stack, teaches you how to build with any teach.
