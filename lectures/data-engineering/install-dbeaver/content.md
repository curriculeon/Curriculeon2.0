# Install DBeaver

## Linux OS
* Execute the command below to install DBeaver
    * `sudo apt -y install dbeaver-ce`

## Mac OS
* Execute the command below to install DBeaver
    * `brew install --cask dbeaver-community`

## Windows OS
* Execute the command below to install DBeaver
    * `choco install dbeaver`
