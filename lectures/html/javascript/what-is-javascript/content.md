### What is
* JavaScript is the language that defines how an application behaves.
* It is executed by a browser or server using a JavaScript engine.
* A simple JavaScript code can be executed in the browser console by opening the console, writing code, and pressing enter.
* JavaScript code can also be written in a separate file and linked to an HTML file.
* A script tag is used in the HTML file to link to the JavaScript file.


### Variables
* A variable can be created using the var keyword.
* Concatenation is the process of adding a variable to a string.
* The prompt() function can be used to ask users for input.
* The alert() function can be used to display a message box.

### Functions
* Functions are used to group lines of code together, and they can be executed by calling them by their function name.
* Functions can take parameters, which are the values they use to do their job.
* By modifying the function signature, parameters can be declared to allow a function to behave differently with different inputs.

### Conditions
* Conditional statements can be used to execute a block of code based on a certain condition.
* The if statement can be used to execute code only if a certain condition is true.
* The == operator is used to check if two values are equal, and the != operator is used to check if two values are not equal.
