# Maven Installation


## Linux Installation
* Execute the command below to install Maven
  * `sudo apt update`
  * `sudo apt install maven`


## Mac OSX Installation
* Execute the command below to install Maven
  * `brew install maven`

## Windows Installation
* Execute the command below to install Maven
  * `choco install maven`
