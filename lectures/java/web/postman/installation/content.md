# Postman Installation



## Linux OS
* Execute the command below to install Postman
    * `sudo snap install postman`


## Mac OSX
* Execute the command below to install Postman
    * `brew cask install postman`

## Windows OS
* Execute the command below to install Postman
    * `choco install postman`
