# NodeJS Installation


## Ubuntu
* Execute the commands below
    * `sudo apt-get install nodejs`

[<img src="./apt-install-nodejs.gif">](./apt-install-nodejs.gif)

## Mac OS
* Execute the command below
    * `brew install node``

## Windows OS
* Open a Powershell as an Administrator.
* Execute the command below
    * `choco install nodejs`

[<img src="./choco-install-nodejs.gif">](./choco-install-nodejs.gif)
