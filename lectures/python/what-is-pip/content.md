# What is `pip`?

## What is a packagemanagement system
* Enables installation and management of additional libraries and dependencies that are not distributed as part of the standard library


## What is `pip`
* `pip` is a _package management system_ for Python.
* `pip` is a recursive acronym for `Pip Installs Packages`.
* `pip` is included by default upon installation, but can be installed by executing the command below in a terminal
    * `python -m ensurepip`




# Creating Requirements.txt from Preexiting Project
* Execute `pip freeze > requirements.txt` from the root directory of the project
