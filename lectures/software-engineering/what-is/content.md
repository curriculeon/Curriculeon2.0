# Software Engineering
### Overview

### What is Software engineering?
Software Engineering is the process of designing, implementing, and maintaining software systems. It involves the use of various tools and methodologies to ensure that the resulting software is of high quality, reliable, and maintainable.

One of the first steps in software engineering is to determine the requirements of the software, which involves gathering and analyzing information about the needs of the users and stakeholders. This information is used to create a detailed specification for the software, which guides its development. Once the specification is complete, the software can be developed using a variety of tools and technologies.
* The **shell and command line interface** are commonly used to interact with the computer and run commands to perform various tasks.

* **Version control** allows multiple developers to work on the same codebase simultaneously and track changes over time and it is an essential tool in software engineering.
* **Git is a popular version control system** that is widely used in the software industry.
* **Github is a web-based** platform that provides hosting for Git repositories, as well as tools for collaboration and version control.
* **Web pages** are an important aspect of many software systems, and are typically developed using a combination of HTML, CSS, and JavaScript.
* **HTML** provides the structure and content of the web page, while **CSS** is used to control its appearance and layout.
* **JavaScript** is a programming language that is commonly used to add interactive elements to web pages.
* In order to serve web pages to users, a software system typically includes an application server and a web server. The **application server** hosts the business logic of the software, while the **web server** is responsible for delivering the web pages to users.
* **Java** is a popular programming language that is widely used in software engineering. It is a high-level, object-oriented language that is easy to learn and use.
* A **database** is a critical component of many software systems, as it provides a persistent storage for the data that the software uses. There are many different databases available, including H2, Hibernate, and MySQL.
* **Java Database Connectivity (JDBC)** is a Java API that is used to access and manipulate databases. It provides a standard set of interfaces that allow Java programs to connect to a database and execute SQL queries.
* The **Java Persistence API (JPA)** is a specification for object-relational mapping in Java. It provides a set of interfaces and annotations that can be used to map Java objects to a relational database.
* An **object-relational mapper (ORM)** is a tool that is used to map the objects in a software system to the relational database that is used to store the data. This allows the software to interact with the database using the objects, rather than having to write SQL queries.
* **Apache** is a well-known open-source software foundation that provides a variety of tools and technologies for software development.
* **Spring Boot** is a popular Java framework that is built on top of the Spring framework and is designed to make it easy to create standalone, production-ready applications.
* A **Database** is A system for storing and managing data, such as information about users, products, or transactions.
* **Cloud Deployment** is making software accessible on a cloud computing platform, such as Amazon Web Services (AWS), Microsoft Azure, or Google Cloud Platform (GCP).
    * The three major cloud computing platforms, Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
* **Build Automation** is the practice of using tools and scripts to automate the process of building, testing, and deploying the software.
* **Continuous Integration** is the practice of frequently merging the changes made by different team members into a shared codebase, and automatically building and testing the software to ensure that it works correctly.
* **Continuous Deployment** is the practice of automatically deploying the software to production whenever the code is updated and passes the tests.
