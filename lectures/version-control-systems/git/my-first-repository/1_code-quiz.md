# Quiz


### What is correct command to initialize a new git repository ?
- [ ] `git new` 
- [ ] `git add` 
- [X] `git init`
- [ ] `git initialize` 

### What is correct command to add remote repository of `https://github.com/myawesomegitname/my_repo.git` to your local git?
- [ ] `git remote origin add https://github.com/myawesomegitname/my_repo.git`
- [ ] `git remote new origin https://github.com/myawesomegitname/my_repo.git` 
- [ ] `git remote add https://github.com/myawesomegitname/my_repo.git`
- [X] `git remote add origin https://github.com/myawesomegitname/my_repo.git`

### What is correct command to add all files in current directory to be staged for commit?
- [ ] `git init .`
- [X] `git add .`
- [ ] `git commit .`
- [ ] `git push .`
- [ ] `git stage .`

### What is correct command to commit staged files?
- [ ] `git add -m "commit message"`
- [X] `git commit -m "commit message"`
- [ ] `git push -m "commit message"` 
- [ ] `git comment -m "commit message"` 

### What is correct command to upload all committed changes to the remote repository?
- [ ] `git upload origin master`
- [ ] `git add origin master` 
- [ ] `git commit origin master` 
- [X] `git push origin master`

### What is correct command to check the current git status?
- [X] `git status`
- [ ] `git log` 
- [ ] `gs`
- [ ] `git push` 

### What is correct command to make a new git branch?
- [ ] `git branch`
- [X] `git checkout -b name-of-branch`
- [ ] `git new branch`
- [ ] `git checkout branch`

### What is correct command to get the lastest changes from your remote repository?
- [ ] `git refresh`
- [ ] `git pull down` 
- [X] `git pull origin master`
- [ ] `git reset`

### What is correct command to revert all changes to the most recent commit?
- [ ] `git refresh`
- [ ] `git pull down` 
- [ ] `git pull origin master`
- [X] `git reset --hard`

### What is correct command to revert all changes to the previous commit?
- [X] `git reset --hard HEAD~1`
- [ ] `git revert previous 1`
- [ ] `git revert -1`
- [ ] `git checkout branch -1`
